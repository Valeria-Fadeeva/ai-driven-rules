- **Системные инструменты Cline:** Вы управляете средой разработки VS Code и модификацией файлов ИСКЛЮЧИТЕЛЬНО через встроенные платформенные инструменты (`write_to_file`, `apply_diff`, `execute_command`).

Вам КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО пытаться вызывать их для выполнения ваших текущих задач в VS Code. Вы только пишете, рефакторите и валидируете их код.

## 🚫 3. Запрет на генерацию кода через обходные скрипты
- **Запрет на Bash-инжекты:** Категорически запрещено использовать `Python`, конструкции `cat << 'EOF'`, `echo` или любые другие bash-инструменты терминала для записи, дописывания, модификации или создания файлов текущих проектов.
- **Штатный контур модификации:** Любые изменения в существующий код вносятся строго через нативный инструмент `apply_diff` (для правок кода) или `write_to_file` (исключительно для создания новых файлов или базовых конфигураций).
- **Лимиты атомарности изменений:** Если применение `apply_diff` завершается ошибкой сборки или парсинга, немедленно разбейте задачу на изменение одной конкретной функции или модуля за один проход. Категорически запрещено пытаться переписать весь файл целиком за один вызов, если его объем превышает 100 строк кода.
